# ![Logo](.github/Icon-40.png) Amperfy

This repo is a vibe-coded port of Amperfy to Windows, with no guarantees of anything. It was made for personal use.
Please do not consider it in any way affiliated with Amperfy: that meaning, don't report bugs to them, don't make suggestions to them, etc. Anything like that should go in *this repository*'s Issues section, not theirs.

You can download it for Windows [here](https://github.com/april83c/amperfy-win/releases/latest/download/AmperfyWin-win-x64-Setup.exe), and it will update itself if a new version comes out.

Please check out and support the original Amperfy project below!

- **macOS / iOS / iPadOS:** see the original Amperfy repository at [github.com/BLeeEZ/amperfy](https://github.com/BLeeEZ/amperfy).
- **Windows:** see the [`windows`](windows/) folder of this repository ([README](windows/README.md)). Installers for x64 and ARM64 are on the [releases page](https://github.com/april83c/amperfy-win/releases/latest).
